Política de Privacidade - Reels Automático

Última atualização: novembro de 2026.

1. Quem somos

O Reels Automático é uma ferramenta pessoal, desenvolvida e usada por José Pereira Lacerda, para criar e publicar vídeos curtos na conta de criador de conteúdo do próprio desenvolvedor no TikTok.

2. Dados coletados

O aplicativo não coleta, não vende e não compartilha dados de outros usuários. Os únicos dados processados são os necessários para a autorização da conta do TikTok do próprio desenvolvedor, como o token de acesso, que fica armazenado localmente no computador de uso do aplicativo.

3. Uso dos dados

Os dados são usados exclusivamente para autenticar a conta e enviar os vídeos gerados para publicação na própria conta. Não são usados para publicidade, perfilamento ou qualquer finalidade comercial.

4. Compartilhamento

Não compartilhamos dados com terceiros, exceto os serviços de API necessários ao funcionamento (como o TikTok e os geradores de imagem, voz e vídeo), e apenas com o conteúdo necessário para a geração e publicação.

5. Armazenamento e segurança

Os tokens e chaves de API ficam armazenados apenas no computador de uso, e não em servidores externos.

6. Seus direitos

Para remover o acesso concedido ao aplicativo, basta revogar a autorização nas configurações de segurança da conta no TikTok.
